# Análisis de Olas de Calor en Xalapa, Veracruz

Proyecto académico de análisis de series de tiempo aplicado al comportamiento de las temperaturas máximas mensuales de Xalapa.

## Periodo de estudio
2000–2025, con 312 registros mensuales.

## Contenido
- Informe técnico.
- Presentación del proyecto.

## Metodología
Exploración de datos, análisis de estacionalidad y tendencia, prueba de estacionariedad, ACF/PACF, selección de un modelo SARIMA y pronóstico a 12 meses.

## Fuente de datos
NASA POWER Data Access Viewer.

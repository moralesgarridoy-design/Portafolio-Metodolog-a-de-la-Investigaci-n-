# Análisis de Componentes Principales (ACP)

Proyecto y actividades académicas de Análisis de Componentes Principales utilizando R.

## Contenido
- Scripts `.R` para ACP, DVS/SVD y construcción de biplots.
- Informes de las actividades.
- Aplicación del ACP a datos socioeconómicos de municipios de México (CONAPO).

## Tecnologías
- R
- FactoMineR
- factoextra
- readxl

## Temas trabajados
Estandarización, matriz de correlaciones, eigenvalores, varianza explicada, componentes principales, DVS/SVD y biplots.

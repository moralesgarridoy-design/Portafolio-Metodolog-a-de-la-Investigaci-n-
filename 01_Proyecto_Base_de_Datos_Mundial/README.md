# Proyecto de Base de Datos — Mundial de Fútbol

Proyecto académico de diseño y gestión de una base de datos relacional utilizando MariaDB/MySQL.

## Contenido
- `mundial.sql`: creación de la base de datos, tablas, limpieza, procedimiento almacenado y consultas.
- `Informe_Proyecto_Base_de_Datos.pdf`: evidencia del proyecto.
- `Informe_Proyecto_Base_de_Datos.docx`: versión editable del informe.

## Tecnologías
- MariaDB / MySQL
- SQL
- R (para conexión y consultas)

## Temas trabajados
Diseño relacional, claves primarias y foráneas, importación de CSV, limpieza de datos, procedimientos almacenados y consultas SQL.
